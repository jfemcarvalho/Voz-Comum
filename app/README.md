# Modelo da aplicação (ODC)

Esta pasta contém o modelo da aplicação **Voz Comum** exportado do ODC Studio (ficheiro `.oml`).

Para o abrir:
1. Instalar o [ODC Studio](https://www.outsystems.com/downloads/) e entrar com uma conta OutSystems Developer Cloud (a Personal Edition é gratuita).
2. Abrir o ficheiro `.oml` no ODC Studio.

A aplicação depende do componente **MapFlow\Leaflet** da Forge, que tem de estar instalado no tenant.

Para ver a aplicação a funcionar sem instalar nada, usar a demonstração:
https://personal-u6frr0hs-dev.outsystems.app/VozComum
